# Evaluation of produced models on test data

Evaluation of produced models on test data

## Usage

``` r
eval_test_data(test_data, final_model, method = "oner", verbose = 1)
```

## Arguments

- test_data:

  Test data.

- final_model:

  Model to be tested.

- method:

  Method used to train model.

- verbose:

  How verbose the logs should be.

## Value

a data.frame with the evaluation statistics
