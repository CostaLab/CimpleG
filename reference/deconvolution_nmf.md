# NMF deconvolution

NMF deconvolution

## Usage

``` r
deconvolution_nmf(weights_mat, values_mat, ...)
```

## Arguments

- weights_mat:

  Reference matrix.

- values_mat:

  New data matrix.

- ...:

  Extra parameters to be set NMF options. Most relevant parameters are
  probably \`method\` and \`beta\`.
